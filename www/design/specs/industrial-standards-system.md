# Web Standards Lab System

The site uses a near-black, layered violet environment. `<open/>` is the
visible browser-native boundary: open, inspectable, and composable.

- Purple light is a precise accent and atmosphere, not a generic page wash.
- Real elements, DSD boundaries, route maps and portable output are the only
  product graphics.
- Typography is expressive in display moments and calm in reading surfaces.
- Motion stages product structure; it never obscures copy or navigation.
- Dark mode is the default brand scene; light mode preserves the same hierarchy.
