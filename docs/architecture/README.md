adapt, scaffold, build, and distribute those products.

This file is the current view of the architecture documents. The authority is
each document's own front matter (`status:` / `topic:` / `summary:`); the block
below is generated by `@openelement/tools-repo#docs-index:write` from those
documents, and a hand edit fails `docs-index:check` in `gate:source`.

## Rules

1. Exactly one active document per topic. A second active statement of the same
   topic is a defect, not a second opinion; `docs-index:check` fails on it.
2. A `historical` record is read-only evidence or design history. It stays in the
   tree because the ledger and the matrix cite it, and it is never cited as an
   active requirement.
3. A change that alters which document is active updates the document front
   matter and regenerates this file with `docs-index:write` in the same commit.
4. Decisions live in the [ADR index](../adr/README.md). Records that no longer
   govern are archived in [`docs/legacy/`](../legacy/README.md), the archive and
   removal register; a superseded reading is never kept beside its successor.
5. Prototypes never count as completion; green CI never counts as browser
   qualification; Alpha16a creates no version, tag, publication or release
   claim.
